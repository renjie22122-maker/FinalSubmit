# London data builder

These scripts assemble, resample, align, and audit the geographic inputs used by the dissertation. The original project repository is <https://github.com/renjie22122-maker/data_builder> (captured local commit `57cb966`). Its MIT licence is retained in this directory.

Only source files are included. The development notebook was excluded because it contained an obsolete embedded API credential; its functional workflow is represented by the standalone scripts. Satellite imagery, panorama files, DSM archives/GeoTIFFs, GeoJSON exports, labels, generated meshes, and visualisation outputs are not redistributed.
